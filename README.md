# Khalil Ansari — Creative Developer

A design-led portfolio for creative development, digital product design, and interactive experiences. Built with React, Vite, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Update the project details and contact address in `src/App.jsx` to reflect current work and preferred contact information.
